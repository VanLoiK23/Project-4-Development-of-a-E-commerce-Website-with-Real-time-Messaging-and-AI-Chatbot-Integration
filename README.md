## 🛠 Tech Stack

* **Frontend:** JSP,CSS
* **Backend:** Java,Spring,Python,WebSocket
* **Database:** MySQL,MongoDB
* **Authentication:** JWT

##  Description

Customers can view and search for products using advanced filters or ask the AI ​​questions. They can chat with the AI ​​to compare products, get product suggestions based on price, and place orders directly. Additionally, for complex questions the AI ​​cannot answer, they can chat with an administrator. The administrator can manage inventory, orders, and provide customer support, etc.
